## Project Description

**Chaya Kudi Justifier** is a humorous web application that generates fake scientific research to justify taking a tea break. With a single click, users receive a convincing-looking productivity study complete with fabricated statistics, confidence intervals, and citations. The application also tracks tea-break productivity trends through a live graph and rewards users with a downloadable certificate.

---

## The Problem (That Doesn't Exist)

Developers, students, and office workers take tea breaks every day, but they rarely have scientific evidence to defend them. This lack of peer-reviewed justification has gone unaddressed for far too long.

---

## The Solution (That Nobody Asked For)

Chaya Kudi Justifier solves this imaginary crisis by generating completely fabricated but highly convincing research findings that "prove" tea breaks improve productivity.

The application:

* Generates randomized research-based excuses.
* Displays fake productivity improvements with statistical jargon.
* Tracks tea-break streaks and productivity spikes.
* Visualizes productivity using a live graph.
* Issues an official Chaya Certificate for dedicated tea enthusiasts.

## How It Works

1. User clicks **"Justify My Chaya Break"**
2. JavaScript randomly generates:

   * A workplace scenario
   * A productivity metric
   * A research statistic
   * A fake academic citation
3. Statistics update automatically.
4. Productivity graph redraws.
5. User can generate and download a Chaya Certificate.
